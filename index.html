최근 분기 요약

각 사 가장 최근 분기의 전년 동분기 대비 증감률

산식: 분기값은 보고서 누적금액 차감(Q4 = 연간 − 3Q 누적) · 영업비용 = 매출액 − 영업이익 · YoY = (당기 − 전년동기) / |전년동기| · 전년동기가 0 또는 없음이면 공란. 금융업(은행·보험·증권)은 매출액 계정이 없어 영업수익으로 매칭되며, 영업비용 정의가 다를 수 있음.
이벤트: 주요사항보고서·거래소공시 제목 키워드 분류(유상증자·CB/BW/EB·소송·영업정지·최대주주변경). 칩을 누르면 DART 원문이 열림. 종속회사 공시는 '(종속)', 원공시가 조회 기간 밖인 정정공시는 '정정'으로 표시. 이벤트 수집은 run.bat의 events 단계.
우발부채·약정 분석은 주석 원문을 LLM(Anthropic API)으로 구조화한 결과이며, 근거 문장과 금액을 원문과 자동 대조해 ✓/⚠ 로 표시함.
